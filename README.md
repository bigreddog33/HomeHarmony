# Hello! 👋

This is a project I've decided to build based on the knowledge I currently have, while also using technologies and taking on challenges I haven't come across yet, in order to stay up to date with the ever-changing world of software development.

The idea is based on an actual household need: having a shared calendar and household planner that is easier to use, edit, and keep in sync as a group.

I am planning to self-host the project and use it in my daily life. At the same time, I want to design it with the possibility of other people using it as well.

My goal is to support **self-hosting** for individuals who value privacy, while also eventually publishing the Android application on **Google Play**.

Both a **web application** and an **Android application** are planned.

Privacy will be an important consideration throughout the project.

The project will remain **open source** and is licensed under the **GNU AGPL-3.0**.
